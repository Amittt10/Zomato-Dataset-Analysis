# Zomato-Dataset-Analysis

This project performs exploratory data analysis (EDA) on the Zomato restaurant dataset to understand patterns in ratings, cuisines, pricing, and locations. The goal is to extract insights that influence restaurant performance and customer preferences.

🛠️ Tools Used
Python

Pandas, NumPy

Matplotlib, Seaborn

WordCloud

📊 Key Insights
Certain cuisines receive consistently higher ratings
Popular locations act as restaurant hotspots
Price does not strongly correlate with ratings
Online ordering and table booking impact ratings positively

📂 Dataset
Kaggle – Zomato Restaurant Dataset
https://www.kaggle.com/datasets/bhanupratapbiswas/zomato
